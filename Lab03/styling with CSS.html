styling with css

In CSS, selectors are patterns used to select the element(s) you want to style.

Selecting Specific Elements with CSS

To select multiple elements, we use commas. Example: h1, h2, p
To select a specific child element in a list, we use :nth-child(). Example: li:nth-child(2)
To select a specific child element within a parent, we use element element:nth-child(n). Example: ul ul li:nth-child(1)
