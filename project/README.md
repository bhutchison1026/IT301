# Project1
Create a static website designed for a specific user group. Choose a group of people and build your site to meet their needs and interests through your content, design, and features.

**Structure and Pages**
- Create 5 different pages. Each page should have unique content and structure, and use different CSS styles to apply everything we’ve learned, while maintaining the same overall design standards.
- Home page must be named index.html.
- Pages should be linked together in a logical way.
- Each page must include a header and a navigation bar.

**Layout and Design** 
- Use CSS media queries to make the layout adjust for large and small screens.
  - Add a comment in your CSS to show where this is done.
  - Add comments to HTML files.
- Include at least one image, with meaningful alt text for accessibility.
- The content should have a adequate consistent spaces. Text does not bleed against the edge of its containing box 5 pts.
- Use at least two different fonts (e.g., one for headings, one for body text).
- Use at least two different CSS positioning methods (e.g., relative, absolute, fixed) to demonstrate your understanding.
- Shared styles must be placed in a single CSS file used by all pages.
  - Avoid repeating the same style rules in multiple places (you will lose credit if you do that).
  - you could place all Nav style in one sheet, footer style in another sheet, colors in one sheet, etc.
- Use external CSS files (no inline or internal styles).
- To help choose the right color for your site you can use any of these sites:
  - Color HuntL
  - Material pallet
  - Contrast checker.

**HTML Features**
- Use semantic HTML elements like <header>, <nav>, <main>, and <footer>.
- Include at least one form with built-in HTML validation (e.g., required, type="email").
- Include links to external websites.
- Your code must pass validation (no errors or warnings) using the Nu HTML Validator.Links to an external site.

**Accessibility**
- All images must include alt text
- Follow WCAG Level A accessibility guidelines
- Test accessibility using Lighthouse in Chrome.
